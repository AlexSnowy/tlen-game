# Монетизация «Земель Тлена» — что настроить

## 1. Яндекс Игры — товары
В консоли разработчика → игра → «Покупки» (сначала подключить монетизацию) создать товары с такими ID:

| ID | Название | Совет по цене |
|---|---|---|
| founder | Набор основателя | 399 ян |
| pass_s1 | Пропуск сезона «Снежная Тьма» | 199 ян |
| ny | Новогодний набор | 79 ян |
| dyes | Краски брони | 69 ян |
| fx | Стихии умений | 99 ян |
| aura | Ауры и следы | 99 ян |
| pet | Спутники-огоньки | 129 ян |
| portal | Облик портала | 69 ян |
| tab | +1 вкладка хранилища | 49 ян |
| slot | +1 место для героя | 49 ян |

С 1 февраля 2027 появится сезон 2 — добавить товар `pass_s2`, с 1 апреля — `pass_s3`.
Покупки сохраняются в облаке Яндекса и восстанавливаются сами.

## 2. Telegram — звёзды (Stars)
Нужен маленький сервер на Cloudflare (бесплатный тариф). Код уже готов в `src/worker.js`.
1. В аккаунте Cloudflare создать KV-хранилище `tlen-pay`, его ID вписать в `wrangler.jsonc` вместо `ВСТАВЬ_ID_KV`.
2. Добавить секреты: `BOT_TOKEN` (токен бота, через которого открывается игра) и `WEBHOOK_SECRET` (любая длинная строка).
3. Выложить сервер (`npx wrangler deploy`).
4. Один раз открыть в браузере `https://<адрес-сервера>/tg/setup?s=<WEBHOOK_SECRET>` — бот начнёт принимать оплату.
   Внимание: если у бота уже есть свой вебхук (другой сервер отвечает на сообщения), он будет заменён.
5. В `public/index.html` вписать адрес сервера в `TLEN_CFG.pay`.

Цены в звёздах: основатель 299, пропуск 149, новогодний 59, краски 49, стихии 79, ауры 79, спутники 99, портал 49, вкладка 39, место героя 39 (меняются в `src/worker.js` и в `SHOP` в `game.js`).

## 3. Реклама за награду
- Яндекс, CrazyGames, GameDistribution, VK — работает сама через их SDK.
- Telegram — сеть Adsgram: зарегистрироваться на adsgram.ai, создать блок типа Reward, вписать его номер в `TLEN_CFG.adsgram`.

## 4. «Поддержать автора» (только на сайте игры)
Завести страницу на Boosty (или аналог) и вписать ссылку в `TLEN_CFG.support`. На площадках и в Telegram кнопка скрыта — там запрещены сторонние оплаты.

## Что уже работает без настройки
Сезон с бесплатной веткой наград, вкладка «Облик», удвоение добычи и воскрешение за ролик на площадках, обычная реклама на площадках.
